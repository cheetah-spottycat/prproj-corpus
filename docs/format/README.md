# Format notes

What is known about Premiere Pro's project format, checked against the corpus.

- [prproj.md](prproj.md): the reference. Each claim is marked *confirmed* (the corpus shows it),
  *code* (FilmCraft's importers agree, no corpus case yet), *conflict* (they disagree, and
  whether the corpus settles it) or *observed* (seen, too few samples).
- [importer-names.md](importer-names.md): every XML name each importer pull request references,
  generated by `python tools/format/inventory.py <filmcraft checkout>`.

To look inside a generated project:

```sh
python tools/format/walk.py out/premiere/27/trim__in-out.prproj VideoClipTrackItem 8 3
```

prints the object with references shown as `-> Class#id`, following them three hops.

Rules: claims come from corpus projects (generated through Premiere's public API) and from
FilmCraft's own importer pull requests, cited by PR and pinned commit. Nothing is taken from
inside Premiere, from Adobe documentation or from third-party parsers. A *code* or *conflict*
entry becomes *confirmed* only through a corpus case.
