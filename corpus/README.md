# Generated corpus

Premiere Pro projects generated by `tools/premiere-projects/` from the case files, with
Premiere's own readback of each (truth JSON), plus the perturbed copies used to see what Premiere
does with what it reads. Every file was written by Premiere or by the corpus scripts, from
synthetic media made with ffmpeg; nothing is hand-made, downloaded or personal.

```text
premiere/27/<area>__<case>.prproj + .json       Premiere Pro 27.0, Windows, German UI
perturbed/27/<area>__<name>--<variant>.prproj   edited copy of a generated project (never saved by Premiere)
             … .request.json                     what was changed, and the copy's sha256
             … .json                             Premiere's readback after opening it
```

- The `.json` next to each project follows the format of the opt-in truth test in
  storytold/filmcraft#4504 (`FILMCRAFT_PREMIERE_TRUTH=corpus/premiere/27`); extra fields are
  allowed. Its `case` field repeats the case definition, so request and readback can be compared.
- Media paths: `FilePath` and `ActualMediaFilePath` hold the absolute path on the machine that
  generated the corpus. `RelativePath` leads to `media/` in this repository (run
  `python tools/premiere-projects/media.py` to create it); importers need only the XML.
- `python tools/format/claims.py corpus/premiere/27 --doc docs/format/prproj.md` checks the format
  notes against these files, without Premiere.
- `python tools/premiere-projects/publish.py` refreshes this folder from a checked local run.
